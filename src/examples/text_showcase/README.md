# NATURA // Text Geometry Showcase

Open `text_showcase.svg` in Inkscape and run DeckMaker. The adjacent `text_showcase.csv` creates four poker-sized cards demonstrating rich SVG text, layered inline icons, visible path decorators and variable-height `shape-inside` frames packed into a dynamic column.

The artwork area also contains horizontal, vertical and `2x2` icon arrays. Some reuse local SVG symbols while others download public-domain Wikimedia Commons plates, crop them independently and arrange them through the same array and Fit-Anchor flow.

The card copy deliberately explains the feature it is rendering. Shorten or extend any ability paragraph, change an inline Fit-Anchor suffix or add another nested `<tspan>`, then regenerate to see the layout adapt.

## Artwork and licensing

All four illustrations are plates from Ernst Haeckel's *Kunstformen der Natur* (1904). Wikimedia Commons identifies these files as public-domain works with no known copyright restrictions:

- [Haeckel Discomedusae 8](https://commons.wikimedia.org/wiki/File:Haeckel_Discomedusae_8.jpg)
- [Haeckel Florideae](https://commons.wikimedia.org/wiki/File:Haeckel_Florideae.jpg)
