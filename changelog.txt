- Add `inline_icons_extra_ratio` preference to tune inline icon text spacing without resizing the icon; default is `0.00`.
- Add `gdrive://` sources for public Google Drive files and folders, including folder paths, glob filters, selectors, iterators, and local cache.
- Add `gdrive_api_key` preference for Google Drive public folder listing.
- Add `network_workers_gdrive` preference and parallel Google Drive downloads; cache folder listings per run.
- Convert `.webp` bitmap sources to cached `.png` files before placement for more reliable Inkscape/export behavior.
- Support quoted local source paths with spaces.
- Fix deep-copy placement to preserve inherited SVG transforms, avoiding oversized generated symbols from scaled template layers.
- Update Source and Snippets documentation for Google Drive, WebP conversion, and current rich-text snippet definitions.
