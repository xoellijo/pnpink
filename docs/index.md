# PnPInk Documentation

![PnPInk Logo](assets/images/pnpink_logo.png)

PnPInk turns an Inkscape drawing and a table of data into complete, editable, multi-page print documents. A single template can produce cards, labels, event badges, boards, tokens, or other variable-data artwork while preserving the visual control of SVG.

If you are new to PnPInk, start with [Basic Workflow](quickstart.md). It builds a small local project from an empty Inkscape document and explains the role of the SVG, IDs, CSV headers, page layout, and generated output. After that, [Dataset Format and Sources](dataset-overview.md) introduces local CSV and Google Sheets projects, while [DeckMaker GUI](deckmaker-gui.md) explains the generation controls.

Use the DSL chapters as references when the basic cycle already makes sense, and consult [Export](export.md) when you are ready to create PDF, PDF/X, images, or cutting files. For offline reading, download the [full PDF guide](https://xoellijo.github.io/pnpink/pnpink.pdf).
